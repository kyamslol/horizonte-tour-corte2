#CASO A horizonte-tour-corte2

Este proyecto consiste en el desarrollo de un algoritmo robusto en **Java** (ejecutado en Visual Studio Code) diseñado para automatizar y gestionar el proceso de selección y cotización de planes vacacionales de una agencia de viajes en Colombia. El sistema permite un flujo continuo de facturación mediante un menú interactivo y asegura la persistencia de los datos mediante archivos de texto (txt). logo y demás imágenes fueron creadas con apoyo de la IA gemini.
